# Pugalenthi K — Interactive Portfolio

A responsive, single-page portfolio with a dark editorial layout, fixed profile rail, straight cursor-reactive grid, flat numbered project rows, and an interactive warm-paper “Field Notes” panel beside the homepage introduction.

## Run locally

1. Extract the project ZIP and open this folder in VS Code.
2. Open `index.html` using Live Server (recommended), or open it directly in a browser.
3. Move the cursor over the homepage grid and the Field Notes panel. Hover or focus each topic tile to explore the labels.
4. Use the project **View on GitHub** links to open the repositories. Project details remain directly in the Projects section; there are no separate case-study pages or buttons.

## Files

- `index.html` — complete single-page portfolio: introduction, projects, about, skills, education, research, certificates, fun facts, and contact.
- `css/style.css` — theme, responsive layout, project rows, card artwork, and Field Notes panel.
- `js/script.js` — interactive grid, card tilt/topic interaction, mobile navigation, active section indicator, India clock, and copy-email control.
- `images/profile_pic.png` — profile portrait used in the sidebar.
- `documents/` — reserved for a resume or supporting documents.

## Technology stack

HTML5, CSS3, vanilla JavaScript, Bootstrap 5.3.8 CDN, Google Fonts (DM Sans and DM Mono). The field-note illustration and project artwork are HTML/CSS, so no project screenshots are needed. Bootstrap and Google Fonts use CDNs and require internet access.
