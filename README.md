# Pugalenthi K — Interactive Portfolio

Welcome to my personal portfolio! This website showcases my academic background, technical skills, projects, research interests, and contact information as an Integrated M.Tech Computer Science and Engineering student at VIT University.

The portfolio features a dark editorial design, interactive elements, numbered project listings, and a **Field Notes** panel that highlights selected areas of interest.

## Features

- **Responsive Design:** Adapts the layout to desktop, tablet, and mobile screens.
- **Single-Page Navigation:** Provides easy access to the different portfolio sections.
- **Interactive Homepage:** Includes cursor-responsive visual elements.
- **Field Notes Panel:** Offers interactive topic tiles that respond to hover and keyboard focus.
- **Project Showcase:** Presents my projects with links to their respective GitHub repositories.
- **Visual Effects:** Uses subtle animations and hover transitions to improve the browsing experience.
- **JavaScript Interactions:** Supports navigation behavior, interactive elements, an India clock, and other interface features.
- **Copy Email:** Provides a control to copy my contact email address when clipboard access is available.
- **CSS-Based Visuals:** Uses HTML and CSS illustrations where appropriate, without requiring project screenshots.

## Technology Stack

- **HTML5** — Structures the website and its content.
- **CSS3** — Handles the layout, styling, responsive design, animations, and visual effects.
- **Vanilla JavaScript** — Implements interactive features and website behavior.
- **Bootstrap 5.3.8** — Supports responsive layouts through its CDN.
- **Google Fonts** — Uses DM Sans and DM Mono for typography.

Bootstrap and Google Fonts are loaded from external CDNs, so an internet connection is required to load these resources.

## Project Structure

```text
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   └── profile_pic.png
└── documents/
```

- `index.html` — Contains the portfolio webpage.
- `css/style.css` — Defines the website's appearance, layout, responsive styles, and effects.
- `js/script.js` — Handles JavaScript interactions.
- `images/profile_pic.png` — Stores the profile picture used on the website.
- `documents/` — Can contain a résumé or other supporting documents.

## Running the Project

1. Open the project folder in Visual Studio Code or another code editor.
2. Open `index.html` in a web browser, or use the Live Server extension in Visual Studio Code for local testing.
3. Navigate through the portfolio sections and explore the interactive elements.
4. Open the project links to view their respective repositories on GitHub.

This is a static website. No package installation or build command is required.
